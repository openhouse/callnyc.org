# CallNYC knowledge bank

This project-internal wiki keeps the preserved interface, present-day claims,
and their public evidence connected without adding public site pages.

The graph distinguishes four things that must not collapse into one another:

- official records and datasets;
- bounded claims supported by those records;
- open questions about the CouncilStat-to-Council Connect transition;
- private ecosystem material used for discovery but not projected as evidence.

The executable copy ledger is
`evals/facts/callnyc-copy-2026-08-13.json`. Run `npm test` against the local
application to verify that every rendered `data-claim-id` resolves to a
supported graph node and that the present-day absence claim retains its date
and limits.

Repository access is not publication permission. Private paths and content stay
outside this public graph; claims on the site cite the underlying public
sources.
