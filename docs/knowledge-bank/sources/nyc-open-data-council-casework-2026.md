# City Council Constituent Services (2015 to 2025)

NYC Open Data identifies this Council dataset as historical. Its 341,299 issue
rows cover all 51 Council accounts; open dates run from January 1, 2015 through
January 9, 2025.

The metadata establishes a substantial preserved dataset, not a live feed. It
does not name Council Connect or explain the publication transition.
