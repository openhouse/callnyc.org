# NYC Open Data Council Connect catalog check

The August 13, 2026 catalog query returned 29 fuzzy matches. None was a New
York City Council dataset named for, or described as an export from, Council
Connect.

This supports a dated “not found” finding. It does not prove universal
nonexistence, and it does not explain a policy or technical decision.
