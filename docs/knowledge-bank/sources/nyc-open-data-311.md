# 311 Service Requests from 2020 to Present

NYC Open Data identifies this as a present-tense dataset updated daily. Its
metadata says each row represents a service request and does not reveal
personally identifying information about the customer.

This is a comparison for public availability, cadence, and privacy-aware
publication—not a claim that 311 and Council constituent casework have the
same operating model or schema.
