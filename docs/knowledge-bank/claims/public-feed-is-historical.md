# The public constituent-services dataset is historical

- **ID:** `claim.public-feed-historical`
- **Status:** Supported
- **Public wording:** NYC Open Data currently describes “City Council Constituent Services (2015 to 2025)” as a historical dataset.

## Limit

Historical status establishes that this public surface is not a live present-tense feed. It does not, by itself, explain when, why, or by whose decision the publication path changed.
