# Decision 0001: Original-first preservation with a compact public action

- **ID:** `decision.contemporary-successor`
- **Date:** 2026-08-13
- **Status:** Adopted for implementation

## Decision

Create a new lineage-preserving CallNYC.org repository from the archival project. The reconstructed 2016 application remains the public root and retains its original route structure. Add one compact header, in the inherited Materialize visual language, that identifies the archive and its author, presents the Politico artifact, and provides a pre-populated transparency email.

`/archive/2016/` remains a compatibility alias, not a second public destination. No additional content page is introduced. Production remains unchanged until an exact candidate is verified on a no-index staging deployment.

## Why

There is no truthful present-tense version of the original rankings while the public dataset is historical. The archive still has civic and professional value as a usable artifact of the 24-hour sprint. Letting visitors enter it directly preserves that value more faithfully than a separate explanatory homepage, while the compact header still makes a bounded request for privacy-protected public data.
