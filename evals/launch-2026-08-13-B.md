# Launch 2026-08-13 B evaluation

This launch candidate is evaluated as an **Experience** surface: a civic hiring reader must encounter the preserved 2016 artifact first, understand its status without leaving it, and have one bounded way to act.

Run the executable evaluation against the served application:

```sh
CALLNYC_EVAL_URL=http://localhost:8080/ php bin/eval-launch-b.php
```

The launch threshold is 100/100 because each criterion is a release requirement, not a discretionary taste score.

| Criterion | Weight | Observable break it catches |
| --- | ---: | --- |
| Artifact first | 30 | A new landing page, database failure, or router regression hides the original navigation, banner, or ranking cards. |
| Single surface | 10 | A visitor must enter a second page before experiencing CallNYC. |
| Preservation truth | 15 | The historical application can be mistaken for a current Council service or its sprint context disappears. |
| Politico evidence | 15 | The notability artifact is missing, unattributed, or no longer opens the preserved source. |
| Prefilled civic action | 20 | The action is not addressed to both institutional data teams or loses its prepared request. |
| Access and safety | 10 | Keyboard entry is lost or historical contact actions become active again. |

The evaluator scores rendered HTML from a running candidate. PHP unit and integration tests separately protect routing, email construction, and component behavior.
